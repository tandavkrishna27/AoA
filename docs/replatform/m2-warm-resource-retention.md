# M2 exact-resource retention and cleanup confirmation

Authenticated resource-truth and resource-reclaimed endpoints supplement the
unchanged frozen lease oracle. They accept only a resource ID and original
physical labels; the company is derived from the exact database lease. Requests
are bounded and remain behind distributed execution, the independent truth-route
flag and the control-plane peer bearer.

Retention first converges any accepted terminal checkpoint. It rechecks current
membership, target generation and verified provider profile, idle expiry, exact
accepted checkpoint and current-turn authority. A same-lease sibling is not
retained. Rollback, revoked authority or quarantine retires ownership before
authorizing cleanup. Re-enabling a flag cannot resurrect retired ownership.

The trusted provider host confirms successful physical destruction separately.
The confirmation is kept in private warm state while the latest lease capability
can still live. Ownership clears only after confirmed cleanup and that deadline;
repeated confirmations do not duplicate the reclaim audit. No credential or
provider operation is issued by these endpoints. Warm issuance defaults off and
rechecks rollback after asynchronous encryption.

The focused group passed 104 tests across six files with Windows PostgreSQL
integration explicitly enabled, without skips. It includes signed broker issuance,
actual third-turn checkpoint retention, siblings and crossed tenants, rollback,
physical confirmation before capability expiry, idempotent clearing and HTTP
peer-auth/body limits. Recursive typecheck passed. The full suite passed 23,876
tests across 2,469 files, with 1,917 tests skipped by their existing environment
guards. The import-composition test timed out on the first full run, then passed
both individually and on the complete rerun. The repository build passed.
All rollout flags and paid provider calls remain off.

Worker-host cleanup is delivered separately. Placement and affinity, consumer
routing, personal/device execution and final integration remain incomplete.
