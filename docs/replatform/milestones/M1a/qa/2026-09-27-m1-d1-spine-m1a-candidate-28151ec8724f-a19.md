## Blocking failure

The spine test image does not make `typescript` available to the runtime call in
`observeFreezeTopology` (`scripts/lib/m1-shipped-boot.mjs`). The failure occurs while evaluating
the first replica/topology assertion:

```text
Error: Cannot find module 'typescript'
Require stack:
- /home/runner/work/AoA/AoA/scripts/lib/m1-shipped-boot.mjs
code: MODULE_NOT_FOUND
```

Because the exception occurs before `evidence.replicas[replica].freezeExclusions` is populated,
the retained profile contains an empty `replicas` object. The freeze requires rendered and running
state for every control-plane replica, all exclusion categories, actual flags, and their digests.
That obligation is absent rather than failed-open, and therefore blocks the gate.

The same early failure skipped all three spine controls. Their absence is independently blocking:
the retained normal evidence cannot prove that usage suppression, duplicate usage, or execution by
the wrong worker would turn the profile red.
