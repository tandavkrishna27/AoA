root dev dependency `typescript`, so the host-side evidence harness fails before it populates
`evidence.replicas[replica].freezeExclusions`. This is not a failure inside any recorded test image.

declared host dependency or remove that undeclared host dependency, then rerun the entire free D1
campaign. No separate finding ticket existed at disposition time; this record does not invent one.

controls independently block a pass. The matrix job's post-job timeout does not erase its useful
evidence, but a cancelled job also cannot turn this all-jobs campaign into a pass.
