## Isolation and repeat rules

disposable containers. Slot tests accept `AOA_WORKER_TEST_DOCKER_LABEL` for explicit
ownership; native restore fixtures use random container names and IDs and dynamic
loopback PostgreSQL ports. Cleanup stops only recorded fixture IDs. Never use a
global Docker prune or shared volume reset.

W02/W05 owns the public review app and DB, Caddy/OAuth, systemd unit/drop-ins and
its existing source/evidence directories. W12 does not redeploy that app, change
rollout flags, copy personal authentication, or use provider credentials. Coordinate
memory-heavy VPS builds between the chats; filesystem isolation alone does not
prevent shared-memory contention.
